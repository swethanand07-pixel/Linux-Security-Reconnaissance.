# Evidence Checklist – Module 02

Add your own screenshots to an `evidence/` folder. Use clear filenames and short captions.

- [ ] `01-linux-navigation.png` – terminal showing `pwd`, `ls -la`, and practice folder
- [ ] `02-file-permissions.png` – permission output before/after `chmod 600`
- [ ] `03-users-processes.png` – sanitized output for `whoami`, `id`, and `ps`
- [ ] `04-dns-lookup.png` – DNS lookup for `example.com`
- [ ] `05-nmap-localhost.png` – Nmap output for `127.0.0.1` only
- [ ] `06-wireshark-capture.png` – short capture showing protocol names, with private data hidden
- [ ] `07-burp-or-zap.png` – proxy history from a local training application only

## Before uploading
- Hide usernames if they are personal, email addresses, public IPs if not needed, cookies, authorization headers, API keys, passwords, and session tokens.
- Do not upload raw packet captures (`.pcap`/`.pcapng`) unless your instructor specifically requires them and you have checked them for sensitive data.
- Do not use screenshots from someone else's work as your own evidence.
