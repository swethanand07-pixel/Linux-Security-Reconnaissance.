# Module 02 – Linux, Security Tools & Reconnaissance

**Duration:** Day 6–Day 10  
**Level:** Beginner  
**Purpose:** Practice Linux fundamentals and learn safe, authorized reconnaissance and basic security-tool workflows.

## Scope and safety
Perform practical work only on your own computer, `localhost` (`127.0.0.1`), or a lab system for which you have explicit permission. Do not scan public IP addresses, college/company networks, or other people's websites. Keep screenshots free of passwords, tokens, personal data, and private IP details where possible.

## Learning objectives
1. Understand Linux files, directories, permissions, users/groups, processes, and basic security.
2. Distinguish passive from active reconnaissance; understand DNS/domain information and network enumeration.
3. Become familiar with Nmap, Wireshark, Burp Suite, and OWASP ZAP.
4. Build and document a controlled reconnaissance lab.

## Repository contents
- `practical-lab-record.md` – ready-to-complete practical record with procedures, observations, and result sections.
- `evidence-checklist.md` – screenshots/evidence to add before submission.

## Suggested workflow
1. Complete the Linux exercises and record the output.
2. Perform DNS lookups for the reserved example domain `example.com`.
3. Use Nmap only against `127.0.0.1`.
4. Capture only your own lab traffic in Wireshark.
5. Configure Burp Suite or OWASP ZAP to inspect a local training application, if available. Do not test a real website without written permission.
6. Add your own screenshots and observations, then commit the files to GitHub.

## Tools
- Linux terminal (or WSL/virtual machine)
- Nmap
- Wireshark
- Burp Suite Community Edition and/or OWASP ZAP
- Git and GitHub
